# MuMuVenmo 2026-08-12 正式版更新说明

## 核心修复

1. **多开不再受 ADB 工作流上限卡住**：登录 Worker 数量与勾选模拟器数量一致，ADB 仅在单条命令执行层做可配置并发调度。
2. **启动不再串行等待**：模拟器按短间隔独立派发，先就绪、代理先连通的实例立即进入登录；单个慢实例不会形成全局屏障。
3. **删除运行期截图负载**：源码不再调用 PNG 截图、`screencap` 或图片 `pull`。UI XML dump 继续用于控件定位、页面识别和结果判断，因此真实登录功能不受影响。
4. **代理池完整联动**：每行使用 `host:port:user:pass|refresh_url`；GUI 可增删；启动前多轮测网；不通时按刷新冷却调用链接并等待后复测；日志记录 VM、Worker 与代理编号。
5. **停止状态收敛**：正常停止等待当前账号完成，强制停止中断当前调用栈；只有线程全部退出后 GUI 才恢复可启动状态，停止后无尾日志。
6. **数据与日志审计**：轮转日志合并监控；账号源文件和四类结果文件原子写入；输入剩余量与结果累计量保持守恒。

## 配置说明

- `workers`：登录 Worker 数量。
- `last_selected_vms`：本次勾选的模拟器序号。
- `adb_command_limit`：同时执行的 ADB 子进程数量；它不是模拟器数量上限。
- `adb_workflow_limit`：登录工作流槽位，建议不小于 `workers`。
- `startup_wave_size` / `startup_wave_settle_seconds`：启动派发节奏。
- `allow_proxy_reuse`：允许健康代理自动复用与分配。
- `proxy_refresh_min_interval_seconds=180`：同一刷新链接最短刷新间隔。

## 发布包说明

发布包不包含真实账号、真实代理、运行日志、导出结果、缓存和临时文件；`config.example.json` 与示例文件可直接复制后填写。Venmo `base.apk` 因体积限制不随 Release 资产上传，其他本地依赖按清单打包。
