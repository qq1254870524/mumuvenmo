# 2026-08-11 SOCKS5 GUI、并行启动与窗口排列修复

## GUI 代理池

- 一行保存一套 `SOCKS5|刷新链接`。
- `+` 新增一行，新增行右侧 `-` 可删除。
- 支持 `host:port`、`host:port:user:pass`、`socks5://user:pass@host:port`。
- 刷新链接可留空；代理与刷新链接不写死在源码中。

## 启动前网络门禁

- 每个 Worker 独立绑定代理并并发执行门禁。
- 代理健康时，该 Worker 立即启动，不等待其他代理。
- 代理不通时调用刷新链接一次，等待 10 秒后重新检测。
- 默认最多检测 5 轮，每轮相隔 10 秒。
- 同一刷新链接 180 秒内只允许调用一次。

## 多模拟器并行

- 勾选的 VM 按 `workers` 数量分别创建独立线程。
- 已完成初始化的 VM 会直接进入登录。
- 缺少 Kitsune、NekoBox 或 Venmo 的 VM 会先独立安装/自愈，完成后自动进入登录，不阻塞其他健康线程。
- 2026-08-11 实机验证 VM 0/1/2/3 均持续领取账号，结果为 `active_recent=4/4`。

## 窗口一行排列

- 默认单窗上限为 360x640，从屏幕左上角开始横向排列。
- `window_auto_fit=true` 只在所有窗口放不下一行时缩小，不再自动放大铺满屏幕。
- 定位前恢复最大化/最小化窗口，避免 `SetWindowPos` 后仍全屏。
- 修复 render 间距校正方向错误，避免窗口越校正越重叠。

## 日志启动

- `logs/run/run_YYYYMMDD.log` 被占用或无写权限时，自动使用进程专用日志文件。
- 日志目录不可写时回退至用户临时目录，GUI 仍可启动。
